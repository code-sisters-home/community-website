Настройка VPN-сервера с использованием OpenVPN начинается с установки необходимых пакетов.

#### Шаг 1: Установка пакетов

Используйте команду:

`sudo apt update && sudo apt install openvpn easy-rsa`

#### Шаг 2: Настройка конфигурации OpenVPN

Затем создайте директорию для конфигурации OpenVPN с помощью:

`make-cadir ~/openvpn-ca`

и перейдите в неё.

Далее настройте параметры сертификатов и ключей. Выполните команду:

`cd ~/openvpn-ca`

и затем:

`source vars && ./clean-all && ./build-ca`

После этого создайте серверный ключ и сертификат с помощью команд:

`./build-key-server server`
`./build-dh`

Также создайте ключ для клиента с помощью:

`./build-key client1`

#### Шаг 3: Настройка конфигурации сервера

Теперь настройте конфигурацию OpenVPN, отредактировав файл `/etc/openvpn/server.conf`. Убедитесь, что правильно указаны пути к ключам и сертификатам, а также настройте порты и протоколы.

После этого запустите сервер командой:

`sudo systemctl start openvpn@server`

Если все прошло успешно, вы сможете подключиться к своему VPN-серверу.
