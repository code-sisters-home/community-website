Настройка сервера PostgreSQL на Ubuntu начинается с установки самого PostgreSQL.

#### Шаг 1: Установка PostgreSQL

Откройте терминал и выполните команду:

`sudo apt update && sudo apt install postgresql postgresql-contrib`

После этого PostgreSQL будет установлен на вашу систему. Убедитесь, что служба PostgreSQL запущена с помощью команды:

`sudo systemctl status postgresql`

#### Шаг 2: Создание пользователя и базы данных

Далее необходимо создать нового пользователя и базу данных. Для этого используйте команду:

`sudo -u postgres createuser --interactive`

чтобы создать пользователя с нужными правами. После этого создайте базу данных с помощью команды:

`sudo -u postgres createdb your_database_name`

#### Шаг 3: Настройка аутентификации

После создания пользователя и базы данных вам нужно будет настроить аутентификацию. Для этого отредактируйте файл конфигурации:

`/etc/postgresql/12/main/pg_hba.conf`

и укажите метод аутентификации, например, `md5` для пароля. После внесения изменений перезапустите службу PostgreSQL командой:

`sudo systemctl restart postgresql`

Теперь вы можете подключаться к базе данных с помощью клиента `psql` или через любой другой интерфейс.
